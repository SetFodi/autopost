# AutoPost campaign launch

## Before launch

- Review the bundled, clearly disclosed showcase transformation on a real
  phone. Replacing it with a real customer transformation is an optional
  upgrade, not a launch blocker.
- If using real campaign media, place every final asset into the documented
  paths before setting `CAMPAIGN_ASSET_SET=real`.
- Ask one person who has actually sold cars:
  - **„შენ რომ მანქანას ყიდდე, ამას გამოიყენებდი?“**
- Do not launch if the result is not clearly stronger than normal Georgian dealer posts.
- Apply the latest Supabase migration to the production project.
- Run `pnpm campaign:check`.
- Confirm the upload flow using a real phone.
- Confirm Meta Pixel events.
- Confirm admin access.
- Confirm the private result page reaches Preview-ready automatically.
- Confirm the TBC test payment unlocks the clean package.
- Confirm WhatsApp support opens with `+995557100020`.

## Campaign

- Budget: approximately 50–60₾.
- Platform: Meta only.
- Primary placements: Facebook Feed, Instagram Stories, and Instagram Reels.
- Do not evaluate success through likes or views.
- Primary metric: completed submissions with real vehicle photos.
- Secondary metric: seller type.
- Strongest metric: actual 14.90₾ payments.

## Decision rules

- Three or more serious uploads: review the generated results and improve any
  weak production template.
- One or two actual payments: keep the automated funnel and test a controlled
  increase in campaign spend.
- Weak first campaign: change creative and run one second small test.
- Two weak creative rounds: treat cars as a meaningful negative.
- Only then consider testing a separate real-estate vertical.
